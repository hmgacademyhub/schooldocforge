Quick Start Guide

The safest workflow for setting up a school, generating documents and protecting data.

Open GeneratorContact HMG

1. Create Profile

Open the app, fill school name, contact details, term/session, colours and logo, then save the profile.

2. Add Records

Use Students, Staff, Fees, Library and other modules. Import CSV samples from the sample-data folder if you want a faster start.

3. Forge Documents

Select document type, customise the fields, preview live, then download PNG/JPG/PDF or add to the print queue.

4. Backup Often

Use Full Backup after major updates. For sensitive school data, tick encrypted backup and keep the password safely.

5. Deploy

Upload the files to GitHub Pages, Vercel, Cloudflare Pages or Netlify. It is a static app: no build step required.

6. Update

When new files are deployed, refresh the PWA update prompt or clear browser cache if a device keeps an older service-worker cache.
