# Detailed Feature Catalog

A web version is available at `feature-catalog.html`. It explains the major modules in administrator-friendly language.

Core categories:

1. Document generation
2. School profile and branding
3. Student and staff records
4. Fees, attendance and reports
5. Library and inventory
6. Academic tools: question bank, exams, quiz, timetable, homework
7. Student services: clinic, transport, cafeteria, hostel
8. Communication: WhatsApp links, mailto links, announcement banner
9. Analytics: KPI dashboard, SVG charts, honor roll, fee trends
10. Security/accountability: PIN lock, encrypted backups, audit log
11. Enterprise governance: policies, risks, incidents, SOPs, vendors, compliance calendar

The system is intentionally free-first and does not use AI APIs.
