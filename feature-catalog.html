Detailed Feature Catalog

Every major SchoolDocForge feature explained in plain language for school owners, administrators, teachers and ICT officers.

Open GeneratorEnterprise Control Centre

Free-first design

SchoolDocForge avoids AI APIs, paid SMS gateways, SMTP servers and mandatory backend hosting. It uses static hosting, local browser storage, CSV files, print/download workflows and free browser APIs.

Document Generator

Create branded letters, certificates, ID cards, report cards, notices, receipts and many other documents from one consistent school profile.

School Profiles

Save multiple school profiles per branch with name, motto, contacts, accreditation details, colours, bank details, logo and document font.

Live Preview

Preview generated documents while typing so school administrators can correct mistakes before printing or downloading.

PDF/PNG/JPG Export

Download finished documents in common formats using free browser-side libraries. No paid document service required.

Student Records

Manage student bio-data, class, admission number, guardian contacts and CSV import/export per branch.

Staff Records

Manage staff roles, departments, contacts and staff IDs with CSV import/export.

Fee Management

Track charges, payments and balances, then generate fee receipts and reports.

Attendance Tracker

Mark daily attendance by class and export reports for monitoring absenteeism.

Library Management

Catalog books, track borrowing/returns and calculate overdue issues.

Inventory Register

Track school assets, tags, custodians, condition and assignment status.

Exam Question Bank

Store questions by subject/class and generate randomized exam papers without AI.

Quiz Player

Run browser-based quizzes from the question bank with automatic grading.

Timetable Builder

Build class timetables and detect conflicts for teachers/rooms.

Clinic Records

Maintain SOAP-style health records, allergies, medication and vaccinations locally.

Transport Routes

Manage buses, routes, drivers, assignments, rosters and bus passes.

Cafeteria Menus

Create weekly menus, printable posters and meal tickets.

Hostel Management

Track rooms, beds, capacity and student occupancy.

Homework Tracker

Assign homework by class and monitor submission status.

Discipline and Merit Log

Record incidents, cautions and merit points with parent notice support.

Visitor Log

Sign visitors in/out, print badges and keep security reports.

KPI Dashboard

Set and monitor targets for enrolment, fee collection, attendance and overdue books.

Expense Tracker

Track income and expenses by category, method and reference.

Sticky Notes

Maintain quick operational reminders on a local note board.

Global Search

Search across students, staff, books, assets, clinic records, questions and notes.

Device Sync via QR

Move data between devices using QR-based transfer for small datasets without cloud cost.

Event Calendar

Maintain school events in a month calendar.

Themes

Switch between light, dark, sepia, high-contrast and solarized themes.

Multi-Currency

Display financial values in NGN, GHS, KES, ZAR, XOF, USD, GBP or EUR.

Bulk QR Codes

Generate many QR codes and download them as a ZIP.

Auto-ID Generator

Create sequential admission numbers or staff IDs.

GPA/CGPA Calculator

Calculate grades using Nigerian, UK or US style scales.

Email/WhatsApp Blast Links

Use mailto and wa.me links for communication without SMTP, SMS gateway or paid API.

Data Bundle Export

Export CSVs and archives for backup or transfer.

PIN Lock and Encrypted Backup

Protect local access with a PIN and encrypt backups with Web Crypto.

Audit Log

Log local create/update/delete actions for accountability.

Enterprise Control Centre

Track policies, risks, incidents, SOP checklists, vendors and compliance dates in the new enterprise module.
